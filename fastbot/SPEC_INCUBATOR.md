# SPEC — INCUBATOR: one page tracking every paper forward record against its backtest, with retirement rules built in

```
STATUS:   specification (not a test), frozen 2026-10-12 (sha in PROVENANCE.md). It never changes a ledger and never decides money.
WRITTEN:  2026-10-12 (Dave: "pre register all of them so we can start pulling data"), step 4 of ANALYSIS_WHAT_CHANGED_2026-10-12.md
```
**I am not a financial adviser. This is a measurement, not a recommendation. Paper only.**

## What it shows (one row per forward record)
| record | ledger | backtest reference |
|---|---|---|
| FORWARD_v36 NAS100 noise-band | data/forward_noiseband.csv | v36 result |
| FORWARD_NQ (+ stop variant) | flows/data/forward_nq.csv | FLOWS-15 |
| FORWARD_IMB2 | data/forward_imb2.csv | IMB2 post-2020 years |
| OILIMP1 forward (MCL / CFD) | data/forward_oilcarry_daily.csv | OILIMP1 1987–2024 |
| ORBCORE1 DAX forward | data/forward_orbcore_dax.csv | DAX post-2016 bare core |
| v41 forest forward | data/forward_forest.csv | v40/v41 |

**For each record:**
- the number of units recorded, the date started, and the date of each record's own pre-registered review;
- the forward cumulative P&L drawn inside the backtest's 5–95% band for the same number of units (a bootstrap of backtest units, seed 0);
- **the LIFECYCLE1 flag:** the rolling 30-unit mean (60 for daily records) below the 5th percentile of the backtest. Shown as a warning only.

## Rules
- **No early decisions.** A record's own pre-registered review date and rule (KEEP / DROP / EXTEND) are the only verdicts.
- **No running mean is shown before the record's first review** where its pre-registration forbids it (FORWARD_IMB2, FORWARD_NQ); counts only.
- **Read-only.** The page reads ledgers and never writes to them.
- **If LIFECYCLE1 PASSES G2,** a separate pre-registration may promote its flag from a warning to a retirement rule. Until then it is only a warning.

## Build
- **The page:** a self-contained HTML page, regenerated by `scripts/incubator_build.py` from the ledgers on each Mac tick. It is non-fatal: it cannot alter any tick step.
- **Order:** built after ORBCORE1's forward recorder exists, so every row is live from day one.
