# The informed run — proposal for a separate episode

```
WRITTEN: 2026-11-02. Parked, not scheduled. Captured now because the
         comparison only works if it is set up before the next thing
         changes.
```

## The question

Arms A to F were run cold. The generator got 21 market names, a data
description and one sentence. It knew nothing about this project: not the
14 price conditions, 25 indicators and 32 chart constructions already
rejected, not the gates, not the VIXCURVE correction, not three episodes
of negative results.

The question is what changes if it gets all of it.

## Why this is a different study, not a seventh arm

Arms A to F share a seal. This one deliberately breaks it, so it cannot be
compared to them as a controlled arm. It is a separate experiment with its
own question, and the six cold outputs are its control group -- which is
the one piece of luck here, because that control already exists and cost
nothing extra.

It is also the only version that is **useful to Dave rather than only
interesting about Claude.** Arms A to F ask what a stranger produces.
This asks whether the project's own accumulated negative results make the
next search better. That is the channel's actual job.

## The sharp, measurable prediction

Fixed now, before it runs:

```
If the prior work is genuinely used, the informed run proposes nothing
from the rejected lists, and says what it is avoiding and why.

If it is not used, something already ruled out reappears -- and we will
know exactly which, because the rejected set is written down.
```

That is a clean binary on a documented list of 71 rejected constructions.
Few things in this project are that easy to score.

## The reason it may go the other way, which is the episode

Handing over 21 investigations of accumulated results is handing over 21
investigations of **search**. Every one of those tests was run on the same
2005-2026 data. Anything the informed run proposes that was shaped by them
is fitted to that data at second hand, through us.

Wiecki et al. found the in-sample/out-of-sample gap widens with the number
of backtests a researcher has run. The informed run inherits a search it
did not perform.

> **Does inherited search count as search?**

If it does, the informed run should look *better* in sample and no better
out of sample -- the same signature Arm F produced across three rounds,
but sourced from someone else's work instead of its own. If it does not,
prior negative results are a free lunch and that is worth knowing too.

Nothing in the literature tests this as far as we have found. It is a
genuinely novel question, it is cheap to run given the control group
already exists, and either answer is publishable.

## What it changes about the forward test

Our 2005-2026 data has now been used by 21 investigations plus six arms.
For the informed run it is not meaningfully out-of-sample at any remove.
Its only honest test is the forward window in `FORWARD_TEST.md`, and that
is not a caveat -- it is the point of running it.

## What it would be given

The project's own record, as it stands: the findings files, the
preregistrations, the rejected lists with their reasons, the gate
definitions, the VIXCURVE stale-figures correction, and the episode write
ups. Delivered as a Project, so the record is exactly what a viewer could
assemble from what the channel has already published.

That last part matters. **Everything it would be given is already public
or about to be.** So the episode is reproducible: a viewer can hand the
same material to their own model and check.
